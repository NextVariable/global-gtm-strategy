# 市场进入决策与交接

本模板仅用于完整项目交接；按任务取所需内容，输出形式服从用户要求。简短问题不必填写此模板。

项目身份：client / product / project；决策 ID/版本/日期：；状态：recommend / provisional / defer。

用一段话回答先进入的地区/语言/具体场景与客户角色，为什么这个选择优于其他候选。如果暂不能决定，直接说明卡在哪项证据与先验证哪个候选。

| 关键判断 | 类别(观察/推断/假设/建议) | 支持证据或前提 ID | 反对证据及限制 |
|---|---|---|---|
| 客户与购买触发 | | | |
| 当前替代与不换理由 | | | |
| 价值、差异与可证明范围 | | | |
| 触达、评估、付款机制 | | | |
| 商业与交付条件 | | | |

说明市场规模是否会改变决策。若估算，给范围、单位、时间、公式、来源/假设、区间与敏感性；否则说明优先补什么。列暂缓的候选与会推翻推荐的变化。

下一验证：对象与筛选、行为、资源/时间上限、负责人或角色、可观察结果、继续/修改/停止条件及理由。尚未执行的动作明确写设计。

后续交接用自然段说明：第二 Skill 的目标/价值/差异/证明边界；第三的市场与触达假设；第四的角色和购买流程；第五的验证口径与停止分支。事实只引用已核验观察，假设仍标假设，禁止宣称项/需刷新项明确列出。

资料：context、evidence/claims/decisions ledger 与 checkpoint 的路径。记录工具使用/失败、预算实际消耗、未取得的材料、隐私限制及恢复 next_action。
