# 验证 · Validation

在仓库根运行 `python3 scripts/validate.py`。检查覆盖 Skill 结构与本地链接、账本身份及引用、区间计算、异常输入和固定种子回归情景。维护中的测试位于 `tests/`，临时结果保存在被忽略的 `.validation-output/`。

Run `python3 scripts/validate.py` from the repository root. Checks cover skill structure and local links, ledger identity and references, interval calculations, invalid inputs, and seeded regression scenarios. Active tests live in `tests/`; temporary output belongs in the ignored `.validation-output/`.

自动检查验证辅助脚本行为，不能证明研究结论正确或真实商业增长效果。既往业务评估尚未证明相对普通模型的净增益，也不支持总体领先的声明。

Automated checks validate helper behavior, not research truth or real commercial growth. Prior business evaluations did not establish a net improvement over a baseline model or overall superiority.
